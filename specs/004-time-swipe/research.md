# 研究：时序卷帘

## 决定：拖动时只改分割位置

- **决定**: 指针移动只更新 0 到 1 的分割比例。换时间才更换那一侧的影像。
- **理由**: 规格要求拖动流畅。每次移动都重建影像会造成卡顿。
- **考虑过的替代**: 用两张截图拼接。用 CSS 裁切而不走地球分割（缩放后会错位）。

## 决定：三种来源先用可替换的演示地址

- **决定**: 本地入库用公开街道图，公开目录用全球卫星影像，历史版本用另一套公开底图，并在署名中写明这是演示、真实历史版本地址由配置替换。
- **理由**: 卷帘操作不依赖后端已发布的 COG 或某个历史服务的版本号。真实地址以后替换 `url` 即可。
- **考虑过的替代**: 先对接 Wayback 的版本接口（条款仍待确认，会挡住卷帘演示）。只做一种来源（不满足规格）。

## 决定：分割比例限制在画面内

- **决定**: 比例夹在 0.02 到 0.98。关闭卷帘再打开时回到 0.5。
- **理由**: 规格边界：分隔条不能拖出画面，重开时回到中间。
- **考虑过的替代**: 允许 0 和 1（一侧完全看不见，像是坏了）。记住上次位置（与「回到中间」冲突）。
