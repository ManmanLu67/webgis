# 数据模型：时序卷帘

不新增数据库表。

## 时相

| 字段 | 规则 |
|---|---|
| id | 字符串，必填，唯一 |
| source | `local`、`stac` 或 `wayback` |
| timeLabel | 字符串，展示用时间 |
| url | 字符串，XYZ 模板地址 |
| attribution | 字符串，必填 |

## 卷帘状态

| 字段 | 规则 |
|---|---|
| enabled | 布尔 |
| position | 数字，0.02..0.98，默认 0.5 |
| leftId | 指向一个时相 |
| rightId | 指向一个时相，可以与左侧相同 |

关闭卷帘时移除两侧对比影像，不删除时相列表。
