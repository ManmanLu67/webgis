# 数据模型：数据源插件

不新增表。沿用数据源行。

## 可用状态

写在数据源配置里的 `availability`：

| 值 | 含义 |
|---|---|
| ready | 可用。不需要账号，或密钥已经提供 |
| needs_config | 需配置。插件在，但不会发出对接请求 |
| skeleton | 未实现。清单状态就是骨架 |

清单状态为 `skeleton` 时，可用状态一定是 skeleton。

## 能否铺到地球

清单字段 `drape` 与 `picker`。接口在状态为可用、且清单允许铺到地球时，才把 `drape` 设为真。图层弹层只使用这一类源。

| picker | 步骤 |
|---|---|
| time | 直接列出时间。第一项是该源的最近一景 |
| extent | 先要地图范围，再按时间取景。没有范围则检索拒绝 |
| template | 用户填写自己的地址，不走目录时间 |

默认「最近」：GIBS 用当前日期减去处理延迟（5 天），不用时钟上的今天；Wayback 把清单按日期从新到旧排列后取第一条；公开目录在范围上加时间，按时间倒序取最新一景。检索体里的 `datetime` 会传给插件。

## 检索结果

与已有目录条目相同：标识、集合、范围、获取时间、云量、资产地址、接入方式。图层地址由插件的 `get_layer_spec` 给出，类型仍是 xyz 或 cog。
