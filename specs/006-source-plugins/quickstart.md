# 快速验证：数据源插件

```text
cd backend
.\.venv\Scripts\python.exe -m pytest tests/test_source_plugins.py tests/test_plugins.py -q
```

启动 API 和前端后，点「图层」。弹层里应有能铺上地球的源（GIBS、历史版本、公开目录、自定义地址）。公开目录要先填地图范围。有时间维的源才选时间，第一项是该源的最近一景。确认后地址里带 `{z}` 的结果铺到三维地球。底图和地形不在弹层里。已挂上的行仍可显隐、调透明度和删除。

`GET /providers` 仍返回全部状态，界面不再单独放一块数据源列表：

- 公开目录、历史版本、GIBS、自定义地址可进弹层
- 本地文件可用，但检索为空，不进弹层
- 地球引擎、官方地图瓦片、天地图为需配置，不进弹层
- 吉林一号、北京一号为未实现，不进弹层
- 腾讯地图不提供瓦片，不进弹层

自动化检查使用样例响应，不访问外网。默认公开目录地址写在 `backend/plugins/public_stac/plugin.yaml`，以该服务当时的官方说明为准。
